# Identifying limitations in using LLM-based conversational systems for Sinhala

## Background and purpose
Large Language Models (LLMs) can significantly improve the quality and efficiency of linguistic and information seeking behaviours
of individuals and communities. However, certain language communities may benefit less from LLMs due to the models' limitations in 
working with a given language. This is particularly the case for low-resource languages, where languages with limited language data, 
technical infrastructure, and human and financial capital may not expereince the same performative power that LLMs display in high-resource
languages such as English.
This repostory contains material probes LLMs with a set of tests to understand how the LLMs perform in Sinhala. 
The purpose of the exercise is to derive thematic insights into the wider limitations noted when LLMs are prompted with Sinhala 
and in the Sinhala-speaking context. 
The repository contains two key components, the material related to the probing tests in separate directories and a discussion that pulls
together the findings in the form of thematic analysis derived from closed reading. 

## Repository content

### Prompts and output from probing tests

This repository contains restuls and findings surfaced from using Large Language Model (LLM)-based conversational systems in Sinhala.

The tests cover three tasks: information retrieval, text generation, and translation. 

The tests used three widely avaialble LLM conversational systems: 
- ChatGPT, based on GPT 5.5; 
- Claude, based on Sonnet 5 Medium;
- DeepSeek, based on Deepseek-V4.

Broadly the tests have been conducted between May 2026 and August 2026.

The findings of the tests are available under three directories: [retrieval](retrieval), [text-gen](text-gen), [translation](translation).
Each directory contains `.txt` files, where one file has the details and LLM output. This inlcudes output from all three LLMs used. 

Each `.txt` file contains some of the following content, depending on what is required for the task:
- Original prompt (in Sinhala);
- English translation of the prompt;
- Source of truth;
- Source;
- Responses generated by all three LLMs, in order of ChatGPT, Claude, DeepSeek.
